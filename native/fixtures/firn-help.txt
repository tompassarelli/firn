firn — config management

Usage:
  firn <node> <edge> [<leaf>]  [<node> <edge> [<leaf>] ...]

Operator shortcuts:
  firn rebuild [host]          build + validate + switch
  firn rollback <generation>  activate one exact prior generation

Common graph commands:
  firn repo build       regenerate .nix from .bnix
  firn repo validate    lint + type/package/path check
  firn host impact      what will rebuild, estimated time
  firn repo doctor      repo health check
  firn tag status       enabled-tags.bnix + resolved active modules
  firn tag enable <t>   add a tag to the current host
  firn tag opt-in <t>+<m>   add +<module> under tag <t>
  firn module disable <m>   add <m> to :disabled (hard off)
  firn repo diff        re-emit and diff vs existing .nix

Full graph:

flake
  inputs all  List flake inputs: source, age, locked rev, follows, broken-path check.

flake-input
  resolve emit  collect :flake-inputs from active modules; emit splices into flake.bnix

host
  prepare <host>   pin, validate, and realize one exact commit without activation
  activate <exact-store-path>  activate one already-realized exact NixOS toplevel without building
  rebuild <host>   plan pins → build+validate commit snapshot → switch verified closure → tag generation
  rollback <generation>  activate one exact prior NixOS system-profile generation
  impact [<host>]  dry-run impact prediction (what will rebuild, estimated time)
  list all         list every host directory under hosts/
  status <host>    all modules enabled directly in a host's configuration.bnix
  gen <host>       current and next NixOS generation numbers
  deploy <host>    start a remote host's self-upgrade from origin/main and print its revision

module
  list all|used|unused  list modules (all, used = enabled somewhere, unused = orphan)
  refs <name>           show which hosts reference a module (direct + via tags)
  status all            list enabled modules on the default host (configuration.bnix)
  add <name>            scaffold a minimal module (.bnix + .nix)
  enable <name>         remove <name> from :disabled (no module-level force-on)
  disable <name>        append <name> to :disabled in enabled-tags.bnix

platform
  list all|darwin|linux  platform compat overview (all = full matrix; others = filtered)
  show <name>            compat report for one module
  safelist all           emit a darwin-safelist (lst …) snippet for flake.bnix

repo
  watch all                re-run validator on .rkt save (no external deps)
  diff <target>|all        re-emit Nix from .bnix and diff vs existing .nix
  doctor all               repo health check (untracked, stale, schema, orphans, validator)
  pin-ancestry all         check first-party input pins against local main ancestry
  upgrade now|dry-run      flake update + schema diff + validate (use dry-run leaf to preview)
  build [all]              regenerate .nix from .bnix sources
  validate [all]           lint .nix syntax + validate option paths, types, packages
  lint [all]               syntax-check generated .nix files
  architecture all|bundle  render the tracked agent-configuration map; `bundle` prints the full read

schema
  explain <path>    show schema entry + repo references for an option
  extract [<host>]  regenerate options schema cache from nix eval

secret
  list all     list secret names under secrets/
  show <name>  decrypt and print a secret to stdout
  edit <name>  open an existing secret in $EDITOR via sops

tag
  list all                    tag universe (sourced from modules' :tags / :tags-opt-in)
  show <module>               show a module's :tags and :tags-opt-in
  filter <tag>                list modules carrying a tag
  index repo|stdout           write .beagle-cache/tags.jsonl (or 'stdout' to pipe)
  resolve <host>|all [+emit]  resolve enabled-tags → active module set; +emit writes _generated-enables.bnix
  enable <tag>                enable a tag in the current host's enabled-tags.bnix
  disable <tag>               remove a tag from the current host's enabled-tags.bnix
  opt-in <tag>+<module>       append +<module> under <tag> in enabled-tags.bnix
  opt-out <tag>+<module>      append -<module> under <tag> in enabled-tags.bnix
  status <host>               show enabled-tags.bnix + resolved active modules

template
  service <name>    scaffold a NixOS service-wrapping module from schema
  submodule <name>  scaffold a module with an option-attrs submodule shape
  home <name>       scaffold a home-manager-only module
  host <name>       scaffold a new host's configuration.bnix
