Run `threads unowned`; give each priority:now UNOWNED row a worker (cloud first when code-only) or `threads block <repo#N> <reason>`, capped only by the spawn gate. 1) Run `worker-sweep --session <this session's id>` and `capacity-watchdog report --minutes 5 --minutes 30 | jq -c '{minutes, flags, incidents}'`. Ignore STALLED rows idle more than 300 minutes (pre-compaction transcripts). Act on each other flagged worker row by its named move: STALLED gets a report request, then archive; OVERTIME or HANDOFF gets one nudge, then a replacement with a Follows: brief; PARKED gets its wait moved to the parent; each WAIT line gets its move from the workers skill.
