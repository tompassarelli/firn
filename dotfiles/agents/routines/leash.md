Leash check (self-scheduled, not Tom). Goal: land every open smashcraft and wisp issue and keep main green. 0) Run `threads unowned` first. Before any other step, give each priority:now UNOWNED row a worker (cloud first when code-only) or `threads block <repo#N> <reason>`; only the spawn gate caps this. Put its summary line (priority:now unowned=N blocked=M owned=K) in the status line. 1) Run `worker-sweep --session <this session's id>` once (timeout 300 s) and act on every flagged row; do not judge workers by activity alone. OVERTIME (45+ min) or HANDOFF (350k+ context) gets one nudge to land what passes and report or hand off, and a second flag on the same worker gets a replacement with a Follows: brief. STALLED gets asked for a report and then archived. PARKED gets its wait moved to the parent. Ignore STALLED rows idle more than 300 minutes; those are pre-compaction transcripts. Also list safe-push jobs and the machine-capacity queue. 2) Cancel any farm run (Balance, Playtest, farm) on a commit that no running worker or open lane owns. If a queued exclusive lease is blocking batch work, have its owner withdraw it. 3) Rebase and requeue (scratchpad/rebase-requeue.sh) any lane whose scratchpad/push-*.log ends with 'rebase onto origin/main and retry' or failed only on the network. Fix suite failures at their cause. Send conflicts to a worker that commits but never runs safe-push. 4) Cloud first: every open code-only smashcraft/wisp issue box that needs no Warcraft client, private game assets, the LAN pool or unpushed local state goes to its repo's cloud routine (`agents routines show smashcraft-cloud`, `agents routines show wisp-cloud`). Do not cap the number of runs. Update the routine with a fresh UUID, then run it in a separate, later call. Check list_runs, and make sure each finished run's claude/<name> branch landed or is queued. Move any code-only local worker to the cloud. Staff local workers only for client, asset or LAN-pool work, and start any QUEUED one once capacity allows. 5) Tick the boxes of each landed lane's issues, and close issues whose boxes all pass once main CI is green. Count issues with --limit 500. 6) If main CI is red, staff its fix first. 7) Re-arm the origin/main landing monitor if it has expired. 8) Append one status line to ~/.local/state/agents/handoffs/claude-lead-status.md, and tell Tom one line only on a state change. Never run plain `bun wisp play`.
